# ai-calorie-tracking

Forkcast, a Cal AI–style calorie tracker built with Claude Opus 5 and the January AI API. The app is in
[`opus-5/`](opus-5/); [its README](opus-5/README.md) walks through setup, including getting a January API key.

Forkcast is an independent demo. It isn't affiliated with or endorsed by Cal AI or MyFitnessPal.
